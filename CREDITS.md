# Credits

ShapeShifter was designed and written by Trysac. No third-party assets are included.

| Asset | Where | How it was made |
|---|---|---|
| The four forms in five skins, tiles, thicket, boulder, signs, effects, backdrops, HUD icons, app icon | `Assets/Art` | Drawn by `tools/art/build.py` (Python standard library) |
| Music (title and run themes) and 22 sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded to Ogg Vorbis with ffmpeg) |
| Scene, UI panel settings, player settings | `Assets/Scenes`, `Assets/UI` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| HUD and menu style | `Assets/UI/Hud.uss` | Written for this project |
| Font | — | Unity's default UI Toolkit runtime font |
| `docs/original/2021-level.png` | `docs/original` | A screenshot of the 2021 version, taken by Trysac. Its tileset and hero sprite were of unknown origin and are not part of this game. |

The PNG writer in `tools/art/image.py` and the synthesizer in `tools/audio/synth.py` are the
author's own helpers, first written for the Qapaq Inqa rebuild.
